# craftipv6

Craft URLs and ipv6 query parts with stable normalization.

**Site:** https://theworker02.github.io/craftipv6/

## Install / run

```bash
git clone https://github.com/theworker02/craftipv6.git
cd craftipv6
node src/cli.js
node --test
```
